# Digvijaysinh Vaghela — Portfolio

Static portfolio website for Software Engineering, Data, and AI/ML co-op applications.

## Run locally

Option 1: open `index.html` directly in a browser.

Option 2 (recommended):
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.

## Publish
This site can be hosted free on GitHub Pages, Netlify, or Vercel. No build step is required.

## Update projects
Edit the project cards in `index.html` and matching case-study content in `script.js`.
